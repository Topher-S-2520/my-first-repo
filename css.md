# CSS basics

- CSS Rule:

selector {
    property: value;
    property: value;
    property: value;
}
- CSS link: `<link> rel="stylesheet" href="style.css">`
- Selectors (precedency rules)
    - Tag: e.g. `body { ... }`, `nav { ... }`
    - Attribute: e.g. `[type=text] { ... }`
    - Class: e.g. `.introdiction { ... }`
    - ID: e.g. `#profile { ... }`
